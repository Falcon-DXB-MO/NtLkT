# ntlkt.com

Static landing page for NtLkT · Intellect Well Engineering. No build step.

## Files
- `index.html`: the page
- `assets/base.css`: design tokens and component classes
- `assets/ntlkt.css`: page styles
- `assets/ntlkt.js`: copy button, VME chart, trajectory / anti-collision chart

## Deploy on GitHub Pages
1. Push this folder's contents to the root of a repository.
2. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. For the custom domain, add `ntlkt.com` under Settings → Pages → Custom domain (this creates a `CNAME` file) and point your DNS at GitHub Pages.
